# Default patterns

## Time series

- Start with a line chart.
- Keep gridlines sparse and light.
- Annotate regime shifts, peaks, troughs, or interventions only when they matter.
- Use small multiples for segmented comparison.

## KPI cards

- Do not show a naked number alone if context matters.
- Add comparison to target, prior period, distribution, or baseline.
- A tiny sparkline is often better than a huge arrow icon.

## Category comparison

- Use bars or dot plots.
- Sort intentionally.
- Direct-label when the category count is modest.
- Use a table if exact lookup dominates.

## Dashboards

- Give each panel a clear analytical job.
- Share scales when comparisons cross panels.
- Put overview and detail in the same field of view.
- Avoid ornamental cards, giant padding, and repeated legends.

## Tables

- Use tables when exact values matter.
- Add sparklines, in-cell bars, or quiet highlighting only if they improve scanning.
- Align decimals and units consistently.

## Small multiples

- Use when the same comparison repeats across segments, geographies, cohorts, or time windows.
- Keep encoding and scales consistent.
- Minimize per-panel clutter.
- Put common explanation outside the panels.

## Annotation

- Prefer one decisive note over many timid notes.
- State the finding, not just the event.
- Keep annotation close to the evidence.
